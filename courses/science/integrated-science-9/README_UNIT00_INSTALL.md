# Unit 00 Installation

## Prerequisite

The Science 9 root files must already exist at:

```text
courses/science/international-integrated-science-9/
```

## Upload destination

Upload the contents of this ZIP directly into that course directory.

The ZIP contains:

```text
course-map.json
diagnostic/
teacher-resources/
docs/
README_UNIT00_INSTALL.md
```

Uploading `course-map.json` replaces the root course map with a version that marks only Unit 00 as `open`. Units 01–12 remain `planned`.

## Expected route

```text
courses/science/international-integrated-science-9/diagnostic/
```

## Post-upload test

1. Open the Science 9 root page and confirm Unit 00 displays as Open.
2. Open the Unit 00 portal.
3. Test all five daily lesson routes.
4. Complete and submit the readiness diagnostic.
5. Confirm the readiness report and item review.
6. Complete the safety verification with an imperfect score and confirm it does not pass.
7. Retake and obtain 15/15.
8. Record the safety agreement and portfolio setup.
9. Open the student record and confirm the local results.
10. Export the Unit 00 JSON record.
11. Print-preview at least one lesson and the student record.
12. Confirm no instructional page links to teacher resources or answer keys.
