# Khaemenes Open-Age Algebra I & Integrated Mathematics I

Course code: `KH-MATH-A1`

This is a placement-based Algebra I course rather than a grade-restricted course. Learners should enter after demonstrating pre-algebra readiness through prior work or the included diagnostic.

## Course totals

- 36 weeks
- 1 readiness diagnostic week
- 34 instructional weeks across Units 01–12
- 1 modelling capstone week
- 87 detailed lessons
- 180 Monday–Friday study sessions
- Foundation, Core, and Extended pathways
- 13 unit mastery checks
- 13 applied investigations
- 36-question diagnostic
- 60-question midterm
- 100-question comprehensive final
- local-first learner records and exports
- parent or evaluator completion record

## Connected tools

The upgraded Khaemenes Scientific Calculator v4 is linked from the header menu, hero, dashboard, and teacher tools. Calculator results support exploration and verification but do not replace written reasoning, units, assumptions, or reasonableness checks.

## Profile integration

The course writes the profile course ID `algebra-1` to `khaemenes-high-pinned-courses-v2`. Add the included `algebra1-profile-bridge.js` script to the High School homepage so the currently deployed profile can display this new course ID.

## Records and privacy

Names, scores, reflections, attempts, and portfolio notes remain in the browser unless the user deliberately prints or exports them. The existing storage key remains unchanged so prior Algebra I progress is preserved.
