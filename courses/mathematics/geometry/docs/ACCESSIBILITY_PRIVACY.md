# Accessibility and Privacy

The course is local-first. Learner names, progress, notes, assessment attempts, and portfolio records remain in browser storage unless the learner or educator explicitly exports them.

Accessibility provisions include semantic headings, keyboard-accessible controls, visible focus, high contrast, light/dark themes, reduced-motion respect, large printable diagrams, accessible SVG titles/descriptions, color-independent diagram markings, Foundation/Core/Extended routes, and printable alternatives for interactive work.
