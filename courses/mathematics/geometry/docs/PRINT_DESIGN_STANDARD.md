# Geometry Print Design Standard

The print system is modeled on a clear illustrated worksheet: prominent geometric figures, restrained purple accent, generous white space, separated problem panels, visible answer space, and a distinct teacher key.

## Required on every lesson

- US Letter page setup with A4-safe margins
- Course, unit, lesson, learner name, and date
- Large vector SVG diagrams with accessible title and description
- Labels, dashed lines, right-angle boxes, tick marks, and text so meaning never depends on color
- Six problem panels arranged in two columns on full-size print
- Sufficient calculation and proof space
- Page-break protection around each figure and question
- Screen-only navigation removed in print
- `Print / Save PDF` control
- Separate teacher key using the same diagrams

## Color and accessibility

Purple is the organizing accent; teal and gold may identify secondary relationships. Grayscale output remains interpretable because every relationship also uses labels, line styles, geometric marks, or written notation.

## Print targets

Lessons, pathway practice, investigations, assessments, administration materials, family guides, teacher guides, and completion records are all printable.
