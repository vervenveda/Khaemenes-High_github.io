# Accessibility, Privacy, and Offline Design

- Open-age, placement-based language
- Foundation, Core, and Extended pathways
- Keyboard-accessible links and controls
- Visible focus indicators
- Responsive single-column layouts
- Reduced-motion support
- Print styles for lessons, assessments, reports, and records
- Local browser storage for names, scores, notes, and attempts
- Explicit exports rather than automatic transmission
- Runtime service-worker caching after first access
- No analytics or third-party record collection in the course package

Local files and public GitHub Pages cannot provide secure multi-user authentication. Families and schools should manage exported records appropriately.
