# Upload Instructions — Grade 11 Social Studies

## Recommended GitHub web upload

1. Download and unzip the packet.
2. Open the `Khaemenes_High.github.io` repository on the `main` branch.
3. Choose **Add file → Upload files**.
4. Drag the packet’s **`courses` folder** onto the upload area. GitHub will preserve the folder paths.
5. Confirm that the upload preview shows `courses/social-studies/grade-11/...` and the replacement `courses/social-studies/index.html`.
6. Commit with a message such as `Add Grade 11 government economics and personal finance suite`.
7. Do not place a second `courses` folder inside the existing `courses` folder. The correct path is exactly:

```text
courses/social-studies/grade-11/index.html
```
