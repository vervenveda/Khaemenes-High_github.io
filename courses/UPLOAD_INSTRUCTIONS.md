# Grade 12 Upload Instructions

## Repository
Upload into the root of:

`vervenveda/Khaemenes_High.github.io`

## Preferred upload
1. Unzip the master packet.
2. Open the repository root on the `main` branch.
3. Upload the packet's **`courses`** folder.
4. Allow GitHub to merge the existing folder structure.
5. Replace these two existing department files when prompted:
   - `courses/social-studies/index.html`
   - `courses/social-studies/README.md`
6. Commit the upload.
7. Do not delete the existing Grade 9, Grade 10, or Grade 11 folders.

## Safer sectional upload
Because the package contains many files, four smaller batch ZIPs are provided:

1. `Grade12_Batch_1_Core_and_Gateway.zip`
2. `Grade12_Batch_2_Weeks_01-12.zip`
3. `Grade12_Batch_3_Weeks_13-24.zip`
4. `Grade12_Batch_4_Weeks_25-36.zip`

Unzip and upload each batch in order. Every batch begins with a `courses` folder so its internal path is preserved.

## Important path rule
Do not upload the outer packet folder into the repository. The repository root should contain:

`courses/social-studies/grade-12/index.html`

It should **not** contain:

`Khaemenes_High_Grade12_Social_Studies_GitHub_Packet/courses/...`

## Expected public routes
- Social Studies gateway:
  `https://vervenveda.com/Khaemenes_High.github.io/courses/social-studies/`
- Grade 12 course:
  `https://vervenveda.com/Khaemenes_High.github.io/courses/social-studies/grade-12/`
- Grade 12 teacher portal:
  `https://vervenveda.com/Khaemenes_High.github.io/courses/social-studies/grade-12/teacher/`

## Post-upload verification
Confirm:
- the department gateway displays Grade 12;
- Grade 12 opens;
- 36 weeks appear;
- Week 1 shows five lessons, three assignments, and ten objective questions;
- the Major Assessments view contains 13 items;
- the Capstone view contains ten checkpoints;
- the Graduation Audit contains 13 mandatory gates;
- the Teacher Portal accepts `KHAE12CAPSTONE`;
- GitHub Pages reports a successful build.
