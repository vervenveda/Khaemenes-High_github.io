# Accessibility and Offline Use

## Included
- Responsive desktop and mobile layout
- Light/dark theme
- Font-size controls
- Text-to-speech for weekly readings when supported by the browser
- Printable weekly packets, assessments, reports, and teacher guides
- Plain HTML, CSS, and JavaScript with no framework dependency
- Browser-local progress records
- JSON export/import for student records
- PWA manifest, service worker, and offline fallback

## Important
Browser-local records are not cloud backups. Export student records regularly and retain printed or external grade records.

The service worker caches core portal files and previously opened pages. First-time access to uncached external links still requires internet access.
