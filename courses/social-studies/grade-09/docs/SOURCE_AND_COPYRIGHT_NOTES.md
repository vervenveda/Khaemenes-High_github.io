# Source, Copyright, and Attribution Notes

The weekly readings, lesson structures, assignment directions, question banks, rubrics, organizers, interface, and original SVG assets in this packet were created for Khaemenes High.

External links point to official institutions, open educational resources, archives, museums, or public educational collections. Those sites retain their own rights, terms, and availability. A link does not mean that the external material is copied into this repository.

Short primary-source study descriptions are instructional summaries. Teachers should consult the linked archive or a legally obtained edition before distributing longer source text.

Recommended classroom practice:
1. Identify creator, title, date, repository, stable URL, and access date.
2. Confirm public-domain or classroom-use status before reproducing an item.
3. Use only the portion needed for instruction.
4. Provide alt text and captions for visual evidence.
5. Retain attribution when adapting open materials.
