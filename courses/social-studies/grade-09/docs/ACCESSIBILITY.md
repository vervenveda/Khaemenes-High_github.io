# Accessibility and Differentiation

- Responsive desktop, tablet, and mobile layout
- Keyboard-visible focus indicators
- Semantic headings, labels, buttons, tables, and navigation
- Browser read-aloud through SpeechSynthesis when supported
- Adjustable font size and light/dark presentation
- Print mode that removes navigation and preserves high contrast
- Chunked readings with headings
- Vocabulary definitions and supported pathways
- Honors extensions
- Oral-response, speech-to-text, text-to-speech, extended-time, and reduced-distraction options at teacher discretion
- No color-only status communication
- No required external media for core completion

Accessibility needs vary. Test the course with the student’s actual browser, assistive technology, and accommodation plan.
