# Assessment System

- 36 weekly quizzes: 10 automatically scored objective questions plus one 5-point constructed response.
- Midterm: 45 objective questions, three short responses, and one evidence-based essay.
- Final: 55 objective questions, three short responses, and one evidence-based essay.
- Retakes: permitted after review and correction.
- Objective responses have definitive answer explanations.
- Open-ended work is scored with evidence, reasoning, accuracy, and communication rubrics.

The main `index.html` provides interactive assessment and local score storage. The standalone HTML files are printable copies. Teacher keys are in `../teacher/`.
