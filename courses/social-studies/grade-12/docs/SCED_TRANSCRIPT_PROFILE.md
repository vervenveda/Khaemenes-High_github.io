## SCED use
The School Courses for the Exchange of Data (SCED) system is a voluntary national course-classification framework. The issuing school or records authority should use the current SCED Finder or current SCED publication to select the closest valid five-digit course code and then record:
- course level;
- available credit;
- sequence;
- local course code;
- local descriptive title.

Do not invent or reuse an obsolete SCED code. SCED is a classification tool, not accreditation and not a substitute for state graduation review.
