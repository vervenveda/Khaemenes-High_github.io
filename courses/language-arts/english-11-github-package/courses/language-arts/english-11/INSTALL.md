# Install English 11

1. Unzip the package.
2. Open `english-11-github-package/courses/language-arts/`.
3. Drag the entire `english-11` folder into the repository folder `courses/language-arts/`.
4. Commit all files together so the folder structure remains intact.
5. Verify `courses/language-arts/english-11/index.html`.
6. Add or update the Grade 11 link on `courses/language-arts/index.html`.
7. Test navigation, quizzes, local progress, printing, backup export/import, and mobile layout after deployment.
