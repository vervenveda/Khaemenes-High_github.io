# Install English 10

1. Upload the entire `english-10` folder to `courses/language-arts/`.
2. Confirm the live path:
   `courses/language-arts/english-10/index.html`
3. Add the English II card or button to the language-arts gateway.
4. Preserve directory names exactly.
5. Update any repository-wide cache manifest or service-worker cache version.
6. Run the checks in `GRADE10_LANGUAGE_ARTS_VALIDATION.md` and `LINK_AUDIT.md`.
