# Grade 10 Language Arts Release

**Release:** 2026-08-05  
**Course:** English II / Grade 10 Language Arts  
**Duration:** 36 weeks  
**Architecture:** 12 units × 3 weeks  
**Technology:** Static vanilla HTML, CSS, and JavaScript

## Release scope

This release converts the earlier single-file 42-week portal concept into a modular 36-week GitHub course architecture aligned with the existing English 9 repository pattern.

## Included

- Course home and progress dashboard
- 12 unit landing pages
- 36 weekly lesson portals
- 180 daily lessons
- Weekly quizzes with retained best scores and corrections
- 12 unit assessments
- Diagnostic, midterm, and final
- Gradebook, attendance, reading log, calendar, certificate
- Portfolio and five scoring rubrics
- Standards coverage matrix and official source links
- Teacher guide and reading selection guide
- JSON curriculum data and JavaScript data bundle
- PWA manifest and course-scoped service worker
- Upload, link-audit, validation, and integration documentation
