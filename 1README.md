Khaemenes High School Online Academy

A modular, GitHub Pages–ready online academy for structured secondary education.

The repository is designed to keep instructional content, printable materials, assessments, laboratory activities, student progress, grading, and course-completion records organized as maintainable files rather than one large application.

Academy Vision

Khaemenes High School Online Academy is designed around a simple educational progression:

Understand → Practice → Apply → Explain → Assess → Review → Master

The academy emphasizes clear instruction, meaningful practice, real-world applications, mathematical reasoning, reflection, and evidence of learning.

The 20-Problem Requirement

Every weekly lesson contains exactly 20 unique problems/questions.

The standard progression is:

Problems

Purpose

1–5

Foundations, vocabulary, basic skills

6–10

Core procedures and direct application

11–14

Mixed concepts and representations

15–17

Real-world applications

18–19

Reasoning and error analysis

20

Challenge problem

The 20 problems should vary numbers, contexts, representations, and reasoning demands.

The student should not encounter twenty cosmetic variations of one question. The goal is meaningful coverage of the week's learning objectives.

Weekly Quiz Standard

Each weekly quiz is concept-complete.

The quiz is not allowed to focus only on the most visible skill of the week while ignoring secondary concepts.

Before a weekly quiz is considered complete, the course assessment blueprint must verify:

Every weekly learning objective is represented.

Every named concept is represented.

Core procedural skills are represented.

Application is represented.

Reasoning or error analysis is represented when appropriate.

Questions are unique.

The answer key has been independently checked.

Each question is mapped to a concept or objective.

Default Weekly Quiz

10 questions

The 10-question format is flexible in distribution. Concept coverage takes priority over a rigid question pattern.

For example, if a week contains five distinct concepts, at least one quiz question must assess each concept before additional questions are assigned to priority skills.

Mastery Rule

A weekly quiz score of 80% or higher demonstrates mastery.

Students below 80% should enter a remediation pathway consisting of:

Review → Correction → Reteach → Retake → Mastery

The academy should preserve the original attempt as well as the reassessment history.

Development Principles

1. Content First

Educational accuracy and instructional clarity come before visual effects.

2. One Source of Truth

Course concepts, questions, assessment metadata, and grading rules should be stored in reusable data structures whenever practical.

3. Accessible by Design

The course should remain usable on desktop, tablet, and mobile devices.

4. Printable by Design

Students must be able to use the course even when they need paper materials.

5. Transparent Assessment

Students should understand how they are being graded and which skills they have mastered.

6. Cumulative Learning

Earlier skills should periodically reappear in later problem-solving so that learning is retained rather than forgotten after a unit test.

7. Error Analysis

Students should learn to identify and explain mathematical mistakes, not simply produce answers.

8. Algebra Readiness

The Pre-Algebra course should deliberately prepare students for Algebra I rather than functioning only as an arithmetic review.
